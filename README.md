# PortSwigger Web Security Academy 学习笔记

> 四川大学网络空间安全学院 · Web 安全学习记录。每篇笔记 = **漏洞原理 + 利用步骤 + 防御视角**，状态区分「技术解析」与「本人实操记录」。

## 为什么写这个仓库

- 对我自己：把"刷过的实验"变成"讲得清的原理"。面试官问"讲一个你做过的 SQL 注入"，我翻开笔记就能讲。
- 对读者：如果你也是 Web 安全入门者，希望我的踩坑记录能帮你少走弯路。

## 笔记状态约定

| 状态 | 含义 |
|---|---|
| 📖 解析 | 依据 Academy 官方教学资料整理的漏洞机制、标准利用链与防御方法，**尚未由本人实操验证**，不计入完成数 |
| ✅ 实操 | 本人已在 Academy 完成，含真实请求、响应与踩坑记录，计入完成数 |

进度表中的「已完成」只统计 ✅ 笔记。解析笔记是刷题前的预习材料，跑完对应 lab 后把「我的利用步骤」换成真实数据，即可改成 ✅。
